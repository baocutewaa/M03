# Báo cáo Kiểm thử Bảo mật Tổng thể – Hệ thống SMS (M03)

## 1. Tổng quan thực thi
- **Kiến trúc & công nghệ:** ASP.NET Core MVC (`.NET 10.0`), SQL Server 2025 Standard Developer Edition (`SMS` + `SMS_Log`), Serilog, EF Core, ClosedXML, HtmlSanitizer.
- **Bộ kiểm thử tự động (`M03.SecurityTests`):** Kiểm thử đơn vị & tích hợp toàn diện từ GĐ0 đến GĐ8 (`EnvironmentBaselineTests`, `Phase2SecurityTests`, `Phase3StudentsCatalogTests`, `Phase4AcademicProcessTests`, `Phase5SecurityTests`, `Phase6PerfDoSMonitoringTests`, `Phase7DbOperationsTests`, `Phase8FinalAuditTests`).
- **Bộ script SQL kiểm chứng:** `Database/verify/verify_gd1.sql`, `perf_benchmark_gd6.sql`, `row_counts.sql`, `verify_gd7.sql`, `verify_all_security.sql`.
